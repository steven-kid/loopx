    Long-Horizon Agent Benchmark Research¶

    This topic folder owns LoopX research on public long-horizon agent benchmarks, external leaderboard strategy, operator-simulator study design, and paper-oriented experiment planning.

    Keep this folder focused on research artifacts:

    • benchmark and paper dossiers;
    • runner setup notes and legality/protocol reviews;
    • official leaderboard versus passive-control-plane versus assisted-simulator experiment plans;
    • result summaries, failure taxonomies, and publication-readiness notes.

    Do not implement LoopX product capability here. Foundational capability work still belongs in the existing code, examples, and contract documents:

    • CLI, quota, status, history, registry, and dashboard behavior belongs under loopx/, scripts/, and the existing contract docs.
    • Deterministic smoke or regression coverage belongs under examples/.
    • General LoopX control-plane specs belong under top-level docs/.
    • This folder may link to those artifacts, but should not become a parallel implementation or a second product-spec tree.
